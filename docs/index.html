mdpkg
Markdown Package · 自包含 Markdown 打包格式规范 v1.0

把一篇带图、分章节的 Markdown 文档，打包成一个可校验、可离线打开、可重复构建的 .mdpkg 文件。

普通 Markdown 的图片是引用，传一个文件就会丢附件。mdpkg 用标准 ZIP 容器加 manifest.json 清单，让文档、资源与引用关系成为一个整体——传输即归档，打开即完整。

核心能力

01资源随包

用原生相对路径写 ![图](assets/a.png)，打包时资源一起进包；引用缺失直接报错，不会静默丢图。

02符号扩展

(tm) → ™、--> → →。只在普通文本中、渲染期生效，不改动原文，解包即原始 Markdown。

03文件包含

<<< includes/ch1.md 在解析前展开，支持嵌套与循环检测——长文档可分章节维护，打包后是一个文件。

快速开始

bash
# 打包：目录 → .mdpkg（图片等资源随包）
mdpkg pack   ./my-doc  -o doc.mdpkg

# 校验：结构 + SHA-256 哈希 + 引用闭包
mdpkg validate doc.mdpkg

# 渲染：单文件自包含 HTML，图片已内联，离线可开
mdpkg render doc.mdpkg   -o doc.html

格式要点

  • 标准 ZIP + manifest.json —— 容器无任何私有格式：任何 unzip 工具都能打开，根目录清单声明版本、入口与资源索引。
  • 可重复构建 —— mtime 固定、条目按路径升序，同输入必产同字节，对 Git 与缓存友好。
  • 三层兼容 —— 容器层（ZIP 通用）、文档层（解包即标准 Markdown）、导出层（render 出纯 HTML），任何一层退化都不丢内容。
  • SHA-256 完整性校验 —— 用于检测损坏、误传与跨平台字节漂移；不防篡改（manifest 与资源同在包内，防篡改需签名，边界见规范）。
